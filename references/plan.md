# plan.json — خطة الريل

ملف واحد بمجلد الشغل. كل التوقيتات **بثواني الفيديو بعد القص** — خذها من `words.json` (أو من اللي بيطبعه `script.py align`: `كلمة|ثانية`).
`timeline.py` بيقراه وبيضبط الحدود لحاله، فما في داعي تكون دقيق لأجزاء الثانية.

```json
{
  "theme":  { "bg": "#272B71", "acc": "#F79210", "ink": "#FFFFFF", "font": "Alexandria", "handle": "@account", "capStyle": "shadow" },
  "knobs":  { "zoom": 1, "dissolve": 0.4, "box": 0.7 },
  "hot":    [ 1.98, { "w": "تفشل", "t": 25.72, "z": 0.12 } ],
  "boxes":  [ { "s": 6.07, "e": 9.75, "panel": { "type": "list", "items": [ { "t": "…", "x": true, "at": 6.55 } ] } } ],
  "over":   [ { "type": "cta", "s": 36.4, "e": 37.7, "t": "الرابط في البايو" } ],
  "broll":  [ { "id": "alarm", "s": 0.6, "e": 1.9 } ],
  "outro":  { "l1": "…", "l2": "…", "chips": ["…"], "cta": "الرابط", "word": "في البايو", "sub": "…" },
  "sfx":    [ { "t": 12.3, "k": "pop", "g": 0.4 } ]
}
```

## theme — الشكل
| الحقل | الافتراضي | فيه |
|---|---|---|
| `bg` | `#272B71` | لون المربع والختام |
| `acc` | `#F79210` | لون التمييز: الكلمة المهمة، الصح، الزر |
| `ink` | `#FFFFFF` | النص |
| `mut` | `#C9CCEA` | النص الخفيف بالختام |
| `dark` | `#14163D` | النص فوق اللون (جوّا الأزرار والفقاعات) |
| `font` | `IBM Plex Sans Arabic` | أي خط عربي من Google Fonts (Alexandria، Cairo، Tajawal، Readex Pro…) |
| `capStyle` | `shadow` | `shadow` نص أبيض بظل · `plate` نص فوق لوح غامق |
| `handle` | — | الحساب تحت كرت الختام |
| `boxTop` | `840` | وين بيبلش كرت الوجه بالمربع (أكبر = رسمة أكبر ووجه أصغر) |
| `faceY` | `0.36` | مكان الوجه بالكادر (0 فوق، 1 تحت) |

الألوان سادة بس، بلا تدرّجات. ألوان العلامة لو عنده.

## knobs — الإيقاع
- `zoom`: قوة الزوم على الكلمات (1 عادي، 0 بلا زوم، 1.3 أقوى).
- `dissolve`: مدة ذوبان البي-رول بالثواني (0.4 مجرّب — أقل من 0.3 خشن).
- `box`: مدة حركة المربع (0.7 مجرّب — أقل من 0.5 خشن).

## hot — الكلمات اللي عليها زوم وتلوين
كل عنصر يا **رقم** (ثانية بداية الكلمة)، يا `{ "w": "الكلمة", "t": ثانية, "z": قوة }`.
- 6-12 بالدقيقة. الهوك، الرقم، الألم، اسم العرض، الدعوة.
- `z` الافتراضي يتبدّل 0.085/0.10. لأقوى 2-3 كلمات: 0.11-0.13.
- لا تحط كلمتين ورا بعض بأقل من 0.6 ث.
- البداية (أول نص ثانية) فيها دفعة خفيفة لحالها.

## boxes — المربعات
الشاشة بتتقسم: لون `bg` فوق فيه الرسمة، والوجه بكرت تحت. `s`/`e` = بداية ونهاية المربع.
- 2-4 بالدقيقة، كل واحد 2-4 ث. ولا مربعين ورا بعض بأقل من 1.5 ث.
- `timeline.py` بيحط الحدود على أقرب بداية جملة (±0.3) وأقرب قطع كاميرا (±0.2).

### `list` — قائمة ✓ / ✕
```json
{ "type": "list", "items": [ { "t": "أحسن منتج بالعالم", "at": 22.1 }, { "t": "ما وصل لزبونك", "x": true, "at": 23.95 } ] }
```
- 2-4 أسطر، كل سطر 1-4 كلمات. `x: true` = ✕ أحمر بدل ✓.
- `at` = لما تنحكى الكلمة. بدونه بيطلعوا كل 0.45 ث.

### `chat` — شات (نقاش)
```json
{ "type": "chat", "bubbles": [ { "t": "ايش أتعلّم؟", "side": "me", "at": 12.45 }, { "t": "برمجة، أكيد", "at": 12.95 } ] }
```
- لـ«كل حدا بيحكيلك إشي»، «سألت الناس»، «الزبون بيقلك». 3-4 فقاعات، كل وحدة 1-3 كلمات.
- `side: "me"` = السؤال (لون التمييز، يسار). الباقي ردود (أبيض، يمين).

### `stat` — رقم بيعدّ
```json
{ "type": "stat", "from": 0, "to": 3, "prefix": "", "suffix": "x", "label": "مبيعات أكثر", "at": 14.2, "dur": 1.2 }
```
فقط لرقم **قاله**.

### `word` — كلمة كبيرة
```json
{ "type": "word", "t": "التسويق", "at": 15.45, "size": 150 }
```
كلمة وحدة أو اثنتين، قوية. `color: "ink"` لأبيض بدل لون التمييز.

### اختياري لكل رسمة
- `nocap: true` = الكابشن ما بيطلع وقتها (لما الرسمة نفسها فيها الكلام).

## over — فوق الفيديو (بدون مربع)
### `title` — عنوان بلوحات
```json
{ "type": "title", "s": 27.5, "e": 29.3, "nocap": true, "y": 1000,
  "lines": [ { "t": "كورس التسويق وصناعة الفيديو", "size": 60, "at": 27.6 }, { "t": "أكاديمية النون", "size": 120, "plate": "acc", "at": 28.15 } ] }
```
- اسم العرض أو الشركة. اللوح بينسحب والنص بيطلع من تحت.
- `plate: "acc"` = لوح بلون التمييز. الافتراضي لون `bg`.
- انتبه للعرض: الشاشة 1080. سطر بـ120 بيوسع ~7 حروف كبيرة؛ أطول من هيك صغّر `size`.

### `cta` — زر فوق مع سهم
```json
{ "type": "cta", "s": 36.45, "e": 37.7, "t": "الرابط في البايو", "at": 36.6 }
```
على «الرابط في البايو» أو «اكتب كلمة … بالتعليقات».

## broll — اللقطات
```json
{ "id": "creator", "s": 29.35, "e": 31.1, "off": 0.2 }
```
- `id` = الاسم اللي عطيته بـ`broll.py add`.
- `s`/`e` = لما يغطي الشاشة. الذوبان بيصير حوالين الحدود.
- `off` = من وين تبدأ اللقطة (ث).
- 3-5 بالدقيقة. لقطتين بفجوة أقل من 0.5 ث بيصيروا موصولين.
- `timeline.py` بيبعدهم عن قطع الكاميرا وعن حركة المربع لحاله، وبيحذّرك لو اللقطة أقصر من الفترة.

## outro — كرت الختام (3 ث بعد الفيديو)
```json
{ "l1": "كورس التسويق وصناعة الفيديو", "l2": "أكاديمية النون", "chips": ["التسويق", "أهداف العمل", "خطة تسويق", "خطة محتوى فيديو"],
  "cta": "الرابط", "word": "في البايو", "sub": "سجّل مقعدك هلقيت" }
```
- `chips`: 2-6 نقاط قصيرة (كلمة إلى 3 كلمات) — اللي فعلاً بيتعلّمه أو بياخده.
- `cta` كلمة كبيرة بيضا، `word` جوّا زر بلون التمييز.
- بدون `outro` الفيديو بيخلص مع آخر كلمة.

## sfx — أصوات إضافية (اختياري)
`timeline.py` بيحط الأصوات لحاله (whoosh للبي-رول، soft للمربع، tick للقائمة، pop للشات والزر، snap للرقم، chime للختام).
بدك إضافي: `{ "t": ثانية, "k": "اسم", "g": 0.4 }`. الأسماء: `chime counter fill pop snap soft star success switch tick whoosh`. ما تزيد عن ~15 بالدقيقة.
